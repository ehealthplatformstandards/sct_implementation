Every eHR component that processes SNOMED CT-coded data (search, validation, reporting, FHIR export, release impact) has its own terminology client and may be configured with its own endpoint. The check verifies that all of them run the production version of the Belgian Edition, that each component refuses to work on another version, and which versions are stamped on stored and exported data. When versions differ, it identifies the components and compares the meaning of every stored concept and the analytics results between the versions.
